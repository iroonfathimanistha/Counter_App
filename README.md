# Counter App 📱

A simple and stylish Counter App built with **React Native** and **Expo**. This beginner-friendly project demonstrates basic state management, interactive buttons, and UI styling in React Native.

## ✨ Features

- ➕ Increase the counter value
- ➖ Decrease the counter value
- 🔄 Reset the counter to zero
- 🔒 Prevent the counter from going below 0 or above 20
- 💬 Display a message based on the current count
- 🎨 Clean and user-friendly interface
- 📱 Run on Android and in a web browser using Expo

## 🛠️ Technologies Used

- React Native
- Expo
- TypeScript
- JavaScript
- React Hooks (`useState`)

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- [Visual Studio Code](https://code.visualstudio.com/)

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/iroonfathimanistha/Counter_App.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Counter_App
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the Expo development server:

   ```bash
   npx expo start
   ```

5. Scan the QR code with Expo Go on your Android device, or press `w` in the terminal to open the app in a web browser.
